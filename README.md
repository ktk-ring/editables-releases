# Editables

스튜디오 make editable의 작업 도구입니다. 영상 · 이미지 변환, 파일 이름 일괄 변경, SVN 형상관리, 텍스처 맵 만들기, 3D 모델 확인을 한 앱에서 다룹니다.

이 저장소에는 설치 파일과 자동 업데이트 파일만 올라갑니다. 소스 코드는 공개하지 않습니다.

## 기능

### 미디어

영상과 이미지를 분석하고 변환합니다. FFmpeg가 함께 설치되어 따로 준비할 것이 없습니다.

- **미리보기**: 프레임 단위로 재생하며 구간(IN · OUT)을 지정하고, 현재 프레임을 PNG로 저장하거나 구간을 GIF · 영상으로 내보냅니다. 재생할 수 없는 형식은 미리보기용 파일을 자동으로 만듭니다.
- **인코딩**: 여러 파일을 프리셋으로 한 번에 변환합니다(MP4 · MOV · MKV · WebM · GIF). 다시 인코딩할 필요가 없으면 컨테이너만 바꿔 화질 손실 없이 빠르게 처리하고, NVIDIA · Apple 하드웨어 인코더를 씁니다. 오디오 · 자막 트랙 선택과 자막 번인도 지원합니다.
- **이미지 시퀀스**: 영상을 PNG · JPG · TIFF · EXR 프레임으로 풀거나, 프레임 묶음을 영상으로 만듭니다. 빠진 프레임을 찾아 알려 줍니다.
- **이미지 변환**: PNG · JPG · WebP · TIFF · AVIF 등으로 일괄 변환하고 크기 · 품질을 정합니다. 이미지 시퀀스는 애니메이션 WebP 한 장으로도 만듭니다.
- **비교**: 여러 영상을 격자(최대 9칸)나 A/B 분할로 나란히 동시 재생하고, 비교 영상 · 이미지로 내보냅니다.
- **라이브러리**: 변환 기록을 날짜별로 보고, 결과 폴더를 열거나 같은 설정으로 다시 변환합니다.

### 리네이머

여러 파일의 이름을 규칙으로 한 번에 바꿉니다. 바뀔 이름을 먼저 미리 보고 적용하며, 적용한 뒤에도 기록에서 되돌릴 수 있습니다.

- 찾아 바꾸기(정규식) · 앞뒤에 붙이기 · 번호 매기기 · 대소문자 · 확장자 · 이름 정리(공백 · 특수문자)
- **UE5 네이밍**: 파일 종류에 맞는 접두사(T_ · SM_ · A_)와 텍스처 맵 접미사(_D · _N · _ORM 등)를 자동으로 붙입니다.
- **시퀀스 재번호**: 프레임 번호를 다시 매깁니다.
- **이름 표(CSV)**: 원래 이름과 새 이름을 적은 표로 바꿉니다. 엑셀에서 편집할 수 있습니다.
- 원본은 그대로 두고 새 이름으로 **사본 만들기**도 할 수 있습니다. SVN 작업 사본 안의 파일은 기록이 끊기지 않게 옮깁니다.

### 형상관리 (SVN)

TortoiseSVN 없이 앱 안에서 SVN을 씁니다. Windows는 svn 명령줄 도구가 함께 설치됩니다.

- **작업 사본**: 변경 확인 · 커밋 · 업데이트 · 잠금 · 되돌리기 · 충돌 해결, 파일별 변경 내용 보기(텍스트 · 이미지)와 이전 버전 받기
- **잠금 현황**: 저장소 전체에서 누가 어떤 파일을 잠갔는지 보고, 오래된 잠금을 정리합니다.
- **잠금 필수**: UE5 에셋(.uasset · .umap)을 잠그기 전까지 읽기 전용으로 만들어, 두 사람이 같은 에셋을 동시에 수정하는 것을 막습니다.
- **프로젝트 셋업**: 체크아웃부터 UE5 무시 목록 · 잠금 필수 설정까지 한 번에 진행합니다.
- 서버 비밀번호는 운영체제 키체인에만 저장합니다.

### 텍스처 도구

베이스 컬러(또는 하이트) 이미지 한 장으로 PBR 맵을 만듭니다.

- 노멀(OpenGL · DirectX) · 하이트 · 러프니스 · AO · ORM 맵을 만들고, 3D(구 · 큐브 · 평면)와 2D로 바로 확인합니다.
- **심리스**: 가장자리를 이어 반복해도 이음매가 보이지 않는 타일 텍스처로 만듭니다.
- **채널 패킹**: 여러 이미지의 채널을 골라 RGBA 한 장으로 합칩니다.
- UE 네이밍(T_이름_N)으로 PNG · TGA · TIFF(8 · 16bit) 내보내기, 설정 프리셋

### 파이프라인

- **3D 뷰어**: FBX · OBJ · glTF · STL 모델을 열어 실제 크기 · 폴리곤 수 · 재질 · UV 펼침을 확인합니다. 와이어프레임 · 점토 · UV 체커 보기를 지원합니다.
- Cinema 4D 익스포트 표준화와 UE5 자동 임포트는 준비 중입니다.

### 공통

- 인코딩 · 텍스처 · 리네이머 프리셋을 파일로 주고받거나 팀 공유 폴더로 함께 씁니다.
- **명령줄 도구**(`editables-cli`): 앱과 같은 기능을 터미널 · 자동화 스크립트 · AI 에이전트(Claude Code 등)에서 씁니다.

## 설치

[Releases](https://github.com/ktk-ring/editables-releases/releases/latest)에서 운영체제에 맞는 파일을 받습니다.

| 운영체제 | 파일 |
| --- | --- |
| Windows 10 · 11 (x64) | `Editables-Setup-<버전>.exe` |
| macOS 12 이상 (Apple Silicon) | `Editables_<버전>_aarch64.dmg` |

`Editables_<버전>_x64-setup.exe` · `*.app.tar.gz` · `*.sig` · `latest.json`은 자동 업데이트용 파일입니다.

### 처음 실행할 때 경고

코드 서명 인증서를 쓰지 않아, 처음 한 번 운영체제 경고가 표시됩니다.

- **Windows**: "Windows의 PC 보호" 창에서 **추가 정보 → 실행**
- **macOS**: DMG에서 Editables를 **응용 프로그램** 폴더로 끌어 놓은 뒤, 앱을 **우클릭 → 열기 → 열기**
  - "손상되었기 때문에 열 수 없습니다"가 표시되면 터미널에서 다음 명령을 실행한 뒤 다시 엽니다.

    ```bash
    xattr -dr com.apple.quarantine /Applications/Editables.app
    ```

## 업데이트

앱이 시작할 때 이 저장소의 `latest.json`으로 새 버전을 확인합니다. 새 버전이 있으면 사이드바에 표시되고, **설정 → 앱 정보**에서 설치 후 다시 시작합니다. 업데이트 파일은 서명으로 검증되며, 서명이 맞지 않으면 설치되지 않습니다.

## 라이선스

- Editables는 무료로 내려받아 쓸 수 있습니다. 소스 코드는 공개하지 않으며, 오픈소스 라이선스는 부여하지 않습니다.
- 모든 권리는 make editable의 김태균에게 있습니다.
- 함께 배포되는 FFmpeg(GPL v3) · Apache Subversion(Apache 2.0) · 글꼴(SIL OFL 1.1) · 라이브러리의 고지는 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)에 있습니다. 앱의 **설정 → 앱 정보 → 오픈소스 라이선스**에서도 볼 수 있습니다.
